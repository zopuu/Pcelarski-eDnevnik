# Pčelarski eDnevnik

Digital beekeeping management system for recording and managing apiaries,
hives, bee colonies, inspections, pasture data, migrations, honey production,
sales, and related analytics.

## Technology Stack

### Backend
- .NET / ASP.NET Core
- Entity Framework Core
- PostgreSQL
- ASP.NET Core Identity
- OpenIddict

### Frontend
- React Native
- Expo
- TypeScript
- Expo Router
- TanStack Query
- React Hook Form
- Zod

### Architecture
- Modular Monolith
- Vertical Slice Architecture
- Feature-first frontend architecture
